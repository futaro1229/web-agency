# Remote Growth Studio

A modern, premium landing page for **Remote Growth Studio** — a web agency serving local businesses in English-speaking markets.

## Stack

- React 19 + TypeScript
- Vite 6
- Tailwind CSS 3

## Sections

- Hero with stats and browser mockup
- Services (Website Design, Landing Pages, AI Development)
- Pricing (3 tiers)
- Testimonials
- Contact form with validation

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173).

## Build for production

```bash
npm run build
npm run preview
```

Output is in `dist/`.
